# Folder gambar

Letakkan foto Anda di sini. Jika file tidak ditemukan, situs otomatis menampilkan placeholder.

- `profile.jpg` — foto profil beranda (rasio 4:5, mis. 1200x1500 px)
- `gallery/` — foto galeri; nama file ada di `src/data/gallery.js`
- `projects/<slug-proyek>/1.jpg, 2.jpg, 3.jpg` — dokumentasi di halaman detail proyek
  (slug: `visco-2025`, `sistem-kinerja-bem-km-ipb`, `ipb-run-2026`, `pkm-pm-pimnas-39`)
- `projects/<slug-proyek>/cover.jpg` — gambar sampul kartu proyek

Format yang disarankan: JPG/WebP, lebar maksimal 1600 px agar situs tetap ringan.
